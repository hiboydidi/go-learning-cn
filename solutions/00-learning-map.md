# 第 0 章参考答案：学习路线

## 练习 0.1

- 变量：保存一个值，方便后续读取或修改。
- 条件：根据判断结果选择不同执行路径。
- 循环：重复执行一段代码，直到达到退出条件。
- 函数：给一组步骤起名字，方便拆分和复用。

## 练习 0.2

一种可执行的 7 天安排：

| 天数 | 目标 |
|---|---|
| 1 | 安装 Go，运行 Hello World |
| 2 | 学会 var、:=、const 和基本类型 |
| 3 | 写 if/else 和 switch |
| 4 | 写 for、break 和 continue |
| 5 | 写 3 个简单函数 |
| 6 | 练习 slice 和 map |
| 7 | 独立写一个统计数字总和的小程序 |

关键不是照抄这张表，而是每天都有一个可以运行和验收的结果。

# 项目 3：日志分析器

## 目标

读取文本日志，统计日志级别、关键词出现次数，并输出一份摘要报告。

## 示例输入

~~~text
2026-11-01 INFO server started
2026-11-01 WARN cache is slow
2026-11-01 ERROR database unavailable
2026-11-01 INFO request completed
~~~

## 功能要求

- 从命令行读取日志文件路径。
- 逐行读取文件。
- 统计总行数。
- 统计 INFO、WARN、ERROR 数量。
- 统计用户指定关键词出现的行数。
- 输出摘要。
- 文件不存在或不可读时返回错误。

## 推荐目录

~~~text
log-analyzer/
├── main.go
├── analyzer.go
└── analyzer_test.go
~~~

## 推荐实现顺序

1. 用 os.Open 打开文件。
2. 用 bufio.Scanner 逐行读取。
3. 每读一行，总行数加一。
4. 判断当前行是否包含 INFO、WARN、ERROR。
5. 用 map 保存各类日志数量。
6. 支持用户传入关键词。
7. 输出统计报告。
8. 为统计函数准备多组输入测试。

## 设计提醒

- 大文件优先逐行读取，避免一次性把整个文件加载到内存。
- 检查 scanner.Err()。
- 不要假设每一行都符合固定格式。
- 如果日志格式复杂，再考虑 regexp 或专门的解析器。

## 验收清单

- [ ] 能统计总行数。
- [ ] 能统计不同级别。
- [ ] 能查找指定关键词。
- [ ] 空文件输出合理结果。
- [ ] 文件不存在时返回错误。
- [ ] 统计逻辑有单元测试。

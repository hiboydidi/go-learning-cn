# 项目 1：命令行计算器

## 目标

编写一个在终端运行的四则运算计算器。这个项目主要练习基础语法，不需要数据库、网络或第三方库。

## 功能要求

- 接收第一个数字。
- 接收运算符：+、-、*、/。
- 接收第二个数字。
- 输出计算结果。
- 除数为 0 时显示错误。
- 输入 q 时退出。

## 建议拆分

~~~text
calculator/
├── main.go
├── input.go
└── calculator.go
~~~

初学时也可以先写在一个 main.go 中，理解以后再拆文件。

## 推荐实现顺序

1. 先用固定数字写出 add、subtract、multiply、divide 四个函数。
2. 给 divide 增加除数为 0 的错误处理。
3. 使用 fmt.Scan 读取两个数字和运算符。
4. 使用 switch 选择对应的计算函数。
5. 用 for 循环支持重复计算。
6. 允许输入 q 退出。
7. 为计算函数编写测试。

## 输入输出示例

~~~text
第一个数字：10
运算符：/
第二个数字：2
结果：5

第一个数字：10
运算符：/
第二个数字：0
错误：除数不能为 0
~~~

## 验收清单

- [ ] 能计算加减乘除。
- [ ] 能处理除数为 0。
- [ ] 能处理不支持的运算符。
- [ ] 能连续计算。
- [ ] 输入 q 能退出。
- [ ] 核心计算函数有单元测试。

## 提示

先不要一次性写完整程序。先完成一个 add 函数，再完成 divide 函数，然后才把它们接入输入流程。
